# 复盘交易室（Replay Trader 中文版）

面向中文用户的历史行情回放与模拟交易练习应用。当前版本使用本地生成的演示行情，不连接券商，也不会执行真实交易。

## 已实现

- 多品种 5 分钟 K 线与成交量展示
- 播放、暂停、逐根移动及 0.5x～4x 倍速回放
- 市价、限价和止损模拟委托
- 多空持仓、加减仓、反手、平仓和实时盈亏
- 当前持仓、待成交委托与成交记录
- 中文交易界面和练习风险提示

## 本地运行

```bash
npm install
npm run dev
```

生产构建和测试：

```bash
npm run build
npm test
```

> 本项目中的行情、报价和成交均为本地模拟数据，仅用于产品演示与交易练习，不构成投资建议。
